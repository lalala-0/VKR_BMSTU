\section{Описание входных и выходных данных}

Входными данными для алгоритма восстановления глубины является путь к существующему в файловой системе изображению
в формате, поддерживаемом OpenCV~\cite{opencv_library}: JPEG, PNG, BMP, TIFF, WebP, PPM, PGM, PBM, SR, RAS.

Результатом работы алгоритма восстановления глубины является нормализованная карта глубин в виде двумерного массива NumPy со значениями в диапазоне [0, 1],
где значения, близкие к 0, соответствуют точкам, расположенным ближе к камере, а значения, приближающиеся к 1, указывают на объекты, удалённые от камеры.

Для визуализации результатов используется цветовая схема <<plasma>>~\cite{hunter2007matplotlib}, согласно которой ближайшие объекты отображаются в темно-синих или фиолетовых цветах, а дальние --- в желто-оранжевых.

Пример визуализации представлен на рисунке~\ref{fig:depth_vis}, где показано исходное изображение и предсказанная алгоритмом карта глубин.

\begin{figure}[H]

    \caption{Пример визуализации карты глубин: слева -- входное изображение~\cite{archive_photo}, справа -- предсказанная карта глубин}

\section{Тестирование}

Для проверки корректности разработанного метода восстановления глубины проведено модульное тестирование
по методологии <<черного ящика>>.

Процесс верификации включает следующие последовательные этапы:
\begin{itemize}
    \item подготовка тестовых изображений, соответствующих каждому классу эквивалентности;
    \item передача входных данных методу восстановления глубины;
    \item обработка изображения предложенным методом;
    \item визуализация полученной карты глубин в цветовой схеме <<plasma>>;
    \item сравнение результата с ожидаемым выводом.
\end{itemize}

Тестирование также включает негативные сценарии с целью подтверждения корректной реакции разработанного метода на нестандартные ситуации и ошибки ввода.

\section*{Вывод}
В технологическом разделе выполнена полная программная реализация гибридного метода восстановления глубины из монокулярных изображений.

В качестве средств программной реализации алгоритмов выбран язык Python, предоставляющий достаточный набор специализированных инструментов для
обработки изображений, использования моделей машинного обучения и визуализации трехмерных данных.

Разработанный алгоритм успешно прошел тестирование на различных типах изображений (цветных, черно-белых, с эффектом сепии)
и продемонстрировал корректную обработку исключительных ситуаций, что подтверждает работоспособность созданного решения.
