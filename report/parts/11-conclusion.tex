\chapter*{ЗАКЛЮЧЕНИЕ}
\addcontentsline{toc}{chapter}{ЗАКЛЮЧЕНИЕ}

Для достижения поставленной цели выпускной квалификационной работы были последовательно решены следующие задачи:

\begin{itemize}
    \item проведен анализ существующих методов восстановления глубины из монокулярных изображений;
    \item разработана формальная модель гибридного метода, объединяющего нейросетевой подход и классический метод определения глубины по закраске изображения;
    \item реализован программный прототип предложенного метода с использованием современных технологий обработки изображений и машинного обучения;
    \item проведено исследование влияния степени состаривания изображения на качество результата применения разработанного метода;
    \item сформулированы рекомендации по применению предложенного метода.
\end{itemize}

В ходе исследования установлено дифференцированное влияние различных типов деградации изображений на точность восстановления глубины:
\begin{itemize}
    \item структурные изменения (шум, виньетирование) оказывают наибольшее негативное влияние (26.8--42.4\% увеличения RMSE);
    \item цветовая деградация (сепия, выцветание) влияет минимально (0.26--1.6\%);
    \item локальные искажения (пятна и царапины) демонстрируют промежуточный эффект между структурными и цветовыми изменениями (около 10.2\%).
\end{itemize}

Разработанный метод имеет четко определенную область применения --- восстановление трёхмерной информации из архивных фотографий для выполнения задач цифровой реставрации и трёхмерной реконструкции исторических объектов
 при наличии фотоматериалов различного качества с минимальным уровнем шумовых искажений.
В таких условиях гибридный метод обеспечивает баланс между устойчивостью
к деградации и детализацией, что подтверждено проведенным исследованием:
точность реконструкции нейросетевого алгоритма повышается на 1--2\% без необходимости переобучения модели.

Перспективными направлениями дальнейшего развития разработанного метода являются:
\begin{itemize}
    \item расширение функциональности для построения полных трехмерных моделей на основе одиночных архивных фотографий,
    \item интеграция с системами дополненной и виртуальной реальности для создания интерактивных исторических реконструкций,
    \item разработка специализированных алгоритмов предварительной реставрации изображений, оптимизированных для последующего восстановления глубины.
\end{itemize}

Таким образом, можно констатировать достижение поставленной цели разработки гибридного метода восстановления трехмерной информации из архивных фотографий.
