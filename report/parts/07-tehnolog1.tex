\chapter{Технологический раздел}

Технологический раздел посвящен практической реализации гибридного метода восстановления глубины из монокулярных изображений.
В данном разделе рассматриваются ключевые аспекты программной реализации и тестирования разработанного решения.
Особое внимание уделяется обоснованию выбора программных средств и библиотек, необходимых для реализации алгоритмов.

\section{Выбор программных средств}

Для реализации методов восстановления глубины из монокулярных изображений был выбран язык программирования Python.
Этот выбор обусловлен наличием в его экосистеме всех необходимых инструментов для комплексного решения поставленных задач, а именно:

\begin{itemize}
    \item OpenCV~\cite{opencv_library}, scikit-image~\cite{van2014scikit} и PIL/Pillow~\cite{clark2015pillow} для обработки изображений, включая фильтрацию, сегментацию и работу с различными форматами файлов;
    \item PyTorch~\cite{paszke2019pytorch} и scikit-learn~\cite{pedregosa2011scikit} для применения предобученной модели MiDaS, что исключает необходимость обучения собственной нейронной сети;
    \item NumPy~\cite{harris2020array}, SciPy~\cite{virtanen2020scipy}, Matplotlib~\cite{hunter2007matplotlib} и Open3D~\cite{zhou2018open3d} организуют работу с многомерными массивами, визуализацию результатов и обработку трехмерных данных.
\end{itemize}

Таким образом, совокупность доступных инструментов Python делает его достаточным инструментом для решения всех аспектов задачи восстановления глубины монокулярного изображения.
