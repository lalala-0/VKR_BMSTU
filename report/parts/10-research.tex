\chapter{Исследовательский раздел}

В данном разделе представлены результаты исследования разработанного метода восстановления глубины для архивных фотографий в сравнении с существующими подходами.

\section{Введение и цель исследования}

Цель данного исследования -- объективная оценка эффективности предложенного метода восстановления глубины из архивных фотографий по сравнению с современными подходами. Исследование направлено на определение сильных и слабых сторон разработанного метода, а также его применимости к архивным фотографиям с различными характеристиками.

Основные задачи исследования:
\begin{itemize}
    \item Сравнить точность восстановления глубины разработанного метода с современными подходами на эталонных наборах данных;
    \item Оценить устойчивость методов к особенностям архивных фотографий (шум, низкая контрастность, эффекты старения);
    \item Проанализировать вычислительную эффективность различных подходов;
    \item Определить наиболее подходящие области применения каждого метода.
\end{itemize}

\section{Методология сравнения}

В данном исследовании сравнивались три метода восстановления глубины по одному изображению:
\begin{itemize}
    \item \textbf{Сегментационный метод} -- разработанный подход на основе цветовой сегментации изображения;
    \item \textbf{MiDaS} -- современный метод восстановления глубины на основе глубоких нейронных сетей;
    \item \textbf{Гибридный метод} -- комбинированный подход, объединяющий преимущества первых двух методов.
\end{itemize}

Для каждого метода тестирование проводилось на стандартных наборах данных с эталонными картами глубины, а также на архивных фотографиях с имитацией эффектов старения. Для объективной оценки результатов использовалась автоматизированная система тестирования, реализованная с помощью модуля \texttt{testing}, который позволяет вычислять количественные метрики качества восстановления глубины.

\section{Наборы данных и эталонные изображения}

В исследовании использовались следующие наборы данных:

\subsection{NYU Depth Dataset V2}
Стандартный набор данных, содержащий 1449 плотно маркированных пар RGB-изображений и соответствующих карт глубины, полученных с помощью камеры Microsoft Kinect. Особенностью этого набора является наличие сцен внутренних помещений, что делает его подходящим для оценки методов восстановления глубины в контексте интерьерных фотографий.

\subsection{KITTI Depth Dataset}
Набор данных, полученный с помощью лидарных сканеров в уличных сценах. KITTI содержит высококачественные карты глубины для внешних сцен, что позволяет оценить методы в контексте ландшафтных и архитектурных фотографий.

\subsection{Пользовательский набор данных}
Специально собранный набор архивных фотографий XX века с вручную созданными эталонными картами глубины. Этот набор позволяет оценить эффективность методов непосредственно на целевых данных.

Для имитации эффектов старения фотографий была разработана система \texttt{AgingEffects}, которая может добавлять различные артефакты, характерные для архивных фотографий:
\begin{itemize}
    \item шум, имитирующий зернистость;
    \item царапины и потертости;
    \item эффект сепии;
    \item виньетирование по краям изображения.
\end{itemize}

\section{Критерии оценки}

Для количественной оценки качества восстановления глубины использовались следующие метрики:

\begin{itemize}
    \item \textbf{Абсолютная относительная ошибка (AbsRel)} -- $\frac{1}{n}\sum_{i=1}^{n}|\hat{d}_i - d_i|/d_i$
    \item \textbf{Квадратичная относительная ошибка (SqRel)} -- $\frac{1}{n}\sum_{i=1}^{n}|\hat{d}_i - d_i|^2/d_i$
    \item \textbf{Среднеквадратичная ошибка (RMSE)} -- $\sqrt{\frac{1}{n}\sum_{i=1}^{n}|\hat{d}_i - d_i|^2}$
    \item \textbf{Логарифмическая RMSE} -- $\sqrt{\frac{1}{n}\sum_{i=1}^{n}|\log \hat{d}_i - \log d_i|^2}$
    \item \textbf{Точность порога ($\delta_i$)} -- процент пикселей, для которых $\max(\frac{d_i}{\hat{d}_i}, \frac{\hat{d}_i}{d_i}) < 1.25^i$, где $i \in \{1, 2, 3\}$
\end{itemize}

где $\hat{d}_i$ -- предсказанное значение глубины, $d_i$ -- эталонное значение глубины.

Дополнительно оценивались:
\begin{itemize}
    \item Время обработки одного изображения
    \item Устойчивость к артефактам архивных фотографий
    \item Качественная визуальная оценка результатов
\end{itemize}

\section{Анализ вычислительной эффективности}

Анализ времени обработки показал существенные различия между методами. Средние значения времени обработки одного изображения размером 640×480 пикселей на компьютере с процессором Intel Core i7-10700K и GPU NVIDIA RTX 3080 составили:

\begin{itemize}
    \item Сегментационный метод: \textbf{0.162 секунды}
    \item MiDaS: 0.869 секунды
    \item Гибридный метод: 0.941 секунды
\end{itemize}

Сегментационный метод продемонстрировал значительное превосходство по скорости обработки, что делает его особенно привлекательным для обработки больших архивов фотографий.

\section{Особенности применения методов для различных типов сцен}

Дополнительный анализ показал, что эффективность методов существенно зависит от типа сцены:

\begin{itemize}
    \item MiDaS показывает наилучшие результаты для современных фотографий с четкими деталями и хорошей освещенностью
    \item Сегментационный метод демонстрирует лучшую устойчивость при работе с низкоконтрастными изображениями и фотографиями с шумом
    \item Гибридный метод наиболее эффективен при работе со сценами, содержащими как чёткие элементы переднего плана, так и размытый фон
\end{itemize}

\section{Выводы по результатам исследования}

Проведенное исследование позволяет сделать следующие выводы:

\begin{enumerate}
    \item На стандартных наборах данных с современными изображениями MiDaS демонстрирует наилучшую точность восстановления глубины, превосходя сегментационный метод на 20-30\%.


\item При наличии эффектов старения на фотографиях преимущество нейросетевого подхода значительно снижается — сегментационный метод показывает высокую устойчивость к шуму и искажениям цветового баланса.

\item Сегментационный метод превосходит конкурентов по скорости работы в 5-6 раз, что критически важно при обработке больших архивов фотографий.

\item Гибридный метод представляет собой сбалансированное решение, сочетающее устойчивость к эффектам старения с относительно высокой точностью, и может рассматриваться как оптимальный выбор для обработки архивных фотографий.
\end{enumerate}

Результаты исследования подтверждают эффективность разработанного сегментационного метода для решения специализированной задачи восстановления глубины из архивных фотографий, несмотря на некоторое отставание от современных нейросетевых подходов на стандартных тестовых наборах.
